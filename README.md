# حسابداری بازرگانی (hesabdari)

سیستم حسابداری تحت وب برای کسب‌وکارهای بازرگانی، به‌ویژه فروش فرش. برنامه با PHP و MySQL ساخته شده و به‌صورت PWA روی دسکتاپ و گوشی نصب می‌شود. رابط کاربری کاملاً فارسی و راست‌به‌چپ است و تاریخ‌ها شمسی هستند.

> **English summary:** A Persian (RTL) web-based accounting system for trading businesses, especially carpet sellers. It has a PHP API, a MySQL/MariaDB database and an installable PWA front end. It covers sales and purchase invoices, inventory, customers and suppliers, checks, bank-statement reconciliation, reports and sales analytics, SMS through Kavenegar, online payments through Zarinpal, and a built-in team workspace (CRM, projects, meetings, chat and web push). No framework and no Composer dependencies are needed, and it runs on ordinary shared hosting or a VPS.

نسخه فعلی: **2.5.2** (مقدار `APP_VERSION` در `api/core/constants.php`). تاریخچه تغییرات در [CHANGELOG.md](CHANGELOG.md) و مستندات فنی کامل در [DOCUMENTATION.md](DOCUMENTATION.md) است.

## امکانات

### فروش، خرید و انبار
- فاکتور فروش و خرید، **پیش‌فاکتور** و تبدیل آن به فاکتور، **فاکتور مرجوعی**
- **کالای امانی** (نزد دیگران / از دیگران) و تبدیل امانی فروخته‌شده به فروش
- محصولات با کد طرح، کالکشن، ابعاد، تصویر و **بارکد**؛ جستجوی دقیق کد تخته و سایز
- انبار چندگانه، موجودی هر تخته با شناسه انبار (`INV-…`)، کاردکس، **انبارگردانی**
- **لیست قیمت**، گروه مشتری با تخفیف، فروشنده با پورسانت
- کنترل فروش بیش از موجودی و سقف اعتبار مشتری (مجاز / هشدار / ممنوع)
- **صفحه اسکن بارکد** برای گوشی
- لینک عمومی فاکتور برای مشتری (با تاریخ انقضا) و پرداخت آنلاین از همان لینک

### اشخاص و حساب‌ها
- مشتریان، تأمین‌کنندگان، **سایر اشخاص** و **شرکا**؛ اتصال مشتری و تأمین‌کننده یک شخص به هم و ادغام
- حساب‌های بانک و صندوق، انتقال وجه، دریافت و پرداخت، علی‌الحساب، تهاتر
- **اقساط** با طرح قسط و پیگیری معوق
- صورتحساب شخص و چاپ آن

### چک‌ها
- چک دریافتی و پرداختی، وصول، خرج چک، **برگشت**، عودت و لغو هر کدام، با سابقه کامل هر چک

### بانک

### هزینه، درآمد و دارایی

- **آنالیز فروش** (صفحه جدا با نمودارها)
- **بستن حساب** دوره و سهم شرکا
- حسابرسی هوشمند و بازبینی مانده‌ها برای پیدا کردن ناهماهنگی‌ها

### میز کار (CRM تیمی)
- **کارهای من** و کارهای تیم، پرونده مشتری با سابقه کامل، ثبت تماس و قول پرداخت
- **بدهکارها** به ترتیب فوریت، **سرنخ‌ها** و تبدیل سرنخ به مشتری
- **پروژه‌ها** (اعضا، کارها، چک‌لیست، پیش‌نیاز، تابلو، گزارش، مستندات، بودجه) و **جلسات** (حاضران، صورت‌جلسه، مصوبات)
- **پیام‌رسان داخلی** (گفتگوی دونفره و گروهی، فایل، پیام صوتی، واکنش، پاسخ، سنجاق)
- **کارتابل** (درخواست پرداخت با تأیید و ثبت هزینه، نامه و ارجاع)، **ایده‌ها** و **پرونده پرسنلی**
- یادآوری‌ها و اعلان روی گوشی با **Web Push** (بدون کتابخانه بیرونی)
- قابل خاموش و روشن کردن کامل از تنظیمات

### پیامک و پرداخت آنلاین
- **پیامک با کاوه‌نگار** (ارسال ساده با خط اختصاصی یا قالب Verify)، یادآور قسط و فاکتور سررسیدگذشته
- **درگاه زرین‌پال** برای پرداخت فاکتور، با تطبیق خودکار پرداخت‌هایی که برگشتشان کامل نشده
- اتصال اختیاری به فروشگاه آنلاین (وب‌هوک امضاشده با HMAC) و ورود یک‌مرحله‌ای (SSO)

### مدیریت و امنیت
- **چند مجموعه تجاری** (چند کسب‌وکار در یک نصب) با جداسازی کامل داده‌ها
- کاربران، نقش‌ها و **کنترل دسترسی** دقیق برای هر بخش
- گزارش فعالیت کاربران، لاگ فنی خطاها، **سطل بازیافت** برای اسناد حذف‌شده
- **پشتیبان‌گیری** دستی و خودکار، ارسال به سرور دیگر یا ایمیل با رمزنگاری اختیاری AES-256، بازیابی با پیش‌نمایش و نقطه بازگشت
- محافظت CSRF و XSS، محدودیت تلاش ورود، قفل حساب، جلوگیری از ثبت تکراری اسناد (Idempotency)
- ورود و خروج داده با CSV و Excel

### PWA
- قابل نصب روی دسکتاپ، اندروید و آیفون، با صفحه آفلاین و به‌روزرسانی خودکار نسخه

## فناوری‌ها

- **سرور:** PHP خالص (بدون فریم‌ورک و Composer)، معماری کنترلر و مدل در `api/`
- **دیتابیس:** MySQL یا MariaDB؛ ساختار در `api/core/schema.php` و ارتقای خودکار با `SchemaMigrator`
- **کاربر:** HTML، CSS و JavaScript با jQuery، Bootstrap 5 RTL، Select2، DataTables، Persian Datepicker، Chart.js، jsPDF و SheetJS (همه داخل `assets/`، بدون CDN)
- **فونت:** وزیرمتن

## پیش‌نیازها

- PHP **8.0 یا بالاتر** (نسخه 8.3 توصیه می‌شود) با افزونه‌های `mysqli`، `pdo_mysql`، `mbstring`، `curl`، `openssl`، `gd`، `zip` و `zlib`
- MySQL 5.7+ یا MariaDB 10.3+
- nginx با php-fpm یا Apache
- HTTPS برای PWA، Web Push و پیام صوتی
- (اختیاری) cron سیستمی برای کارهای زمان‌بندی‌شده

## نصب

1. فایل‌ها را در پوشه وب سرور قرار دهید.
2. فایل تنظیمات را بسازید و اطلاعات دیتابیس را در آن وارد کنید:
   ```bash
   cp api/config.example.php api/config.php
   ```
3. در مرورگر `setup.php` را باز کنید. جدول‌ها ساخته می‌شوند و کاربر `admin` با یک **رمز تصادفی** ایجاد می‌شود که فقط همان یک‌بار نمایش داده می‌شود. آن را یادداشت کنید و بعد از ورود عوضش کنید.
4. بعد از نصب، `setup.php` را از دسترس عموم خارج یا حذف کنید.
5. (توصیه‌شده) cron هر دقیقه:
   ```cron
   * * * * * php /path/to/hesabdari/cron.php
   ```
   سپس در «تنظیمات ← قوانین و رفتار سیستم»، اجرای کارهای زمان‌بندی‌شده را روی «کران خارجی» بگذارید.
6. پوشه‌های `uploads/`، `storage/work/`، `backups/` و `logs/` باید برای کاربر وب سرور قابل نوشتن باشند.

## ارتقا

- قبل از هر ارتقا از دیتابیس و پوشه‌های `uploads/` و `storage/work/` پشتیبان بگیرید.
- `api/config.php` را نگه دارید. این فایل در گیت نیست و با ارتقا عوض نمی‌شود.
- تغییرات دیتابیس **خودکار** است: اولین درخواست API بعد از تغییر `APP_VERSION` همه مهاجرت‌ها را یک‌بار اجرا می‌کند. اجرای دستی هم ممکن است: `setup.php?upgrade=1` (با ورود) یا از خط فرمان `php api/upgrade_integration.php` برای جدول‌های اتصال فروشگاه.

## نکات امنیتی

این مخزن عمومی است. هیچ‌وقت فایل تنظیمات، رمزها، پشتیبان‌ها، آپلودها، لاگ‌ها یا خروجی‌های بانکی و مشتریان را commit نکنید. `.gitignore` همه این‌ها را کنار می‌گذارد.

روی سرور، این مسیرها **نباید** از وب قابل دسترسی باشند: `api/` (به‌جز `api.php`)، `backups/`، `logs/`، `storage/`، `docs/`، `tests/`، `tools/`، `templates/`، `backend/`، `analytics/lib/` و فایل‌های `setup.php`، `cron.php` و `.installed`. اجرای اسکریپت در `uploads/` هم باید بسته باشد.

- روی **Apache** فایل‌های `.htaccess` داخل همین پوشه‌ها این کار را انجام می‌دهند.
- روی **nginx** این فایل‌ها خوانده نمی‌شوند. از نمونه `docs/deploy/nginx-hesabdari-hardening.conf` استفاده کنید و پیشوند `/hesabdari/` را با مسیر نصب خود هماهنگ کنید.
- پشتیبان‌ها بهتر است بیرون از پوشه وب نگهداری شوند.

## ساختار پوشه‌ها

```
api/            API سمت سرور
  controllers/    کنترلرهای هر بخش
  models/         مدل‌ها و منطق داده
  core/           هسته: ساختار دیتابیس، مهاجرت، زمان‌بندی، پیامک، Web Push، پشتیبان و …
  helpers/        کمکی‌ها (زرین‌پال، تصویر و …)
analytics/      صفحه آنالیز فروش
assets/         CSS، فونت‌ها، آیکون‌ها و کتابخانه‌های جاوااسکریپت
js/             ماژول‌های جاوااسکریپت هر بخش
templates/      قالب‌های PHP بخش‌ها و پنجره‌ها
tests/          تست‌های خط فرمان (php tests/<name>_test.php)
docs/           طراحی‌ها و نمونه پیکربندی استقرار
tools/          ابزارهای توسعه (مثلاً ساخت آیکون PWA)
storage/work/   فایل‌های میز کار (در گیت نیست)
uploads/        تصاویر و فایل‌های آپلودی (در گیت نیست)
index.php       برنامه اصلی (SPA)
api.php         نقطه ورود API
invoice.php     نمایش عمومی فاکتور
pay.php         شروع پرداخت آنلاین
scan.php        صفحه اسکن بارکد
cron.php        اجرای کارهای زمان‌بندی‌شده
setup.php       نصب و ارتقای دستی
sw.js           Service Worker برای PWA
```

## روال توسعه و استقرار

GitHub مرجع اصلی کد است:

1. تغییرات را روی نسخه محلی (مثلاً Laragon یا XAMPP) انجام و تست کنید: `php tests/<name>_test.php`
2. `APP_VERSION` را در `api/core/constants.php` بالا ببرید تا مهاجرت دیتابیس و کش PWA به‌روز شوند.
3. commit و push به شاخه `main`.
4. روی سرور فقط از GitHub بگیرید (`git pull`) و مستقیم روی سرور ویرایش نکنید.
