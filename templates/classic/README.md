# قالب کلاسیک (منجمد)

این پوشه کپی دقیق قالب‌های برنامه پیش از بازطراحی ۲.۶ است و فقط برای قالب «کلاسیک» استفاده می‌شود.

- ظاهر این فایل‌ها عمداً تغییر نمی‌کند.
- تا وقتی قالب کلاسیک هست، **هر امکان تازه‌ای که به قالب‌های `templates/` اضافه می‌شود باید اینجا هم اضافه شود.** `tests/ui_parity_test.php` شناسه‌های دو طرف را با هم مقایسه می‌کند.
- `scripts.php` بین دو قالب مشترک است و فقط در `templates/` قرار دارد.
- برای حذف قالب کلاسیک: این پوشه، شاخه `classic` در `index.php`، گزینه `classic` در `api/core/ui_theme.php` و `assets/css/dark-mode.css` را حذف کنید.
